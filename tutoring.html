一节课怎么上

  1. 先找到卡点

    先弄清楚你卡在哪里：是概念没懂、练得不够，还是前面的基础漏了。从那个点开始讲，而不是从课件第一页开始念。

  2. 讲到原理那一层

    尽量找一个贴切的比喻，再配一个最小的例子，让你知道它为什么是这样，而不只是记住怎么写。

  3. 请你讲回给我听

    用你自己的话讲一遍，或者当场写几行代码。讲得清楚了再往下走，讲不清楚就说明还差一点。

  4. 课后写反馈

    这节讲了什么、哪些已经掌握、哪些还要练、下次建议做什么，都写下来发给你。

举个例子

很多刚学 Python 的同学会在这里卡住：明明改的是 b，为什么 a 也变了？

a = [1, 2, 3]
b = a
b.append(4)
print(a)    # [1, 2, 3, 4]

“变量不是盒子，而是贴在盒子上的标签。b = a 并没有复制出一个新盒子，只是在同一个盒子上又贴了一张标签 b。所以通过 b 往盒子里放东西，从 a 看过去也就变了。”

接着我会请你先预测：如果把第二行改成 b = a.copy()，最后会打印什么？
